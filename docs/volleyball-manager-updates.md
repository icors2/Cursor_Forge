# Volleyball Manager — club UX updates

Source list used for Wave 1 polish and Wave 2 registration.

## Wave 1 — module notes

- **Home:** Top bar should span the system as buttons, not text-only links.
- **Live:** Need a way to input live statistics.
- **Calendar:** Need a way to upload a calendar link, and imported iCal should land in the current game format.
- **News:** Comments under updates. Admin/coach can delete comments or mute commenters.
- **Volunteer:** Openings should be clickable to sign up (not a placeholder list).
- **Coach:** Rename to "Stat Tracking". Select which game is being recorded.
- **Notes:** Already in good order.
- **Teams:** Scheduling a game must persist. Roster add must not require dues. Label inputs. Players from a dropdown with a manual-add option.
- **Seasons:** Previous seasons need game/player stats plus a printable history.
- **Dues:** Admin must be able to mark dues paid.
- **Theme:** Per-account color, self-serve (not admin-only team colors).

## Wave 2 — admin + registration

- **Admin:** One console to run the club.
- **Team registration:** Coach sets up a team apply window. A parent or player makes one account and applies to that team (Coach → Player). Unlimited teams.
- **Player pool:** Applicants land in a pool so the coach can build the team.
- **Roster:** Coach sets the team and player positions.
