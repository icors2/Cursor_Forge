# Assets

Templates and catalogs for agents. Read these; do not load them all into always-apply rules.

| Path | Use |
| --- | --- |
| `mcp-catalog.md` | Copy-ready MCP server configs |
| `checklists/bootstrap.md` | First-run checklist |
| `checklists/security-review.md` | Security review pass |
| `checklists/definition-of-done.md` | Gate before claiming done |
| `reference/` | Structure, API contracts, observability, threat model |
| `templates/` | Skill/rule skeletons, GitHub, CI, config, Docker, env, hooks |
| `stack-playbooks/` | How to scaffold a product once the user wants one |

During bootstrap, copy only what this project needs. Leave the catalog in place unless the user wants a lean repo.
